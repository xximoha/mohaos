# MOHA OS

Content Operating System — Personal content management for Moha.

## Stack
- Single HTML file (HTML + CSS + JS)
- localStorage for data persistence
- Anthropic API for AI features
- PWA-ready (installable on iOS/Android)

## Deploy
Auto-deployed to Netlify on every push to `main`.

## Structure
- `index.html` — Main app (all logic)
- `manifest.json` — PWA manifest
- `icon-192.png` / `icon-512.png` — App icons
